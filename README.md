# Warhammer Figures

El desarrollo de nuestro proyecto consiste en formar un codigo basado en la venta de figuras del universo Warhammer 40k, integrando JPA  hibernate, modelado y normalización, bean validation, excepciones y respuestas, estructura CSR, respuesta REST, integración de logs estructurados con SLF4J, comunicación con microservicios y integración de herramientas de trabajo colaborativo y gestión de versiones como git.

Cada desarrollo de codigo fue integrado en su propia rama para de forma continua integrar comandos de git dentro de las terminales de Visual y GitBash para hacer pull request y de manera seguida un merge desde cada rama a la main, de forma continua el proyecto se baso en una BD graficada para de manera continua crear una donde se subira y guardaran los datos que se ingresen dentro de las pruebas con XAMPP.
(El proyecto se desarrollo durante la semana del 04/05/26 hasta el domingo 10/05/26)

# Ramas Integradas para el desarrollo:

main → (default branch) Tronco principal del proyecto, reside el código que se considera "estable" o listo para producción.

Categoria/Imagen → Representa las categorias dentro del propio proyecto junto con la imagenes guiadas con URL.

Edicion/Figuras → Almacena las figuras, figura y las ediciones de las mismas.

Feature/marca-enlace → Desarrollo de marcas y enlaces junto con URL.
